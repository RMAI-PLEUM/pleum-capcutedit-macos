# Pleum CapCutEdit for macOS

A distributable Codex and Claude skill package for inspecting and editing local CapCut Desktop projects on macOS.

## Get started

- Read [START-HERE-Pleum-CapCutEdit-macOS.md](START-HERE-Pleum-CapCutEdit-macOS.md) for the three-step setup guide.
- Download [Pleum-CapCutEdit-macOS.zip](Pleum-CapCutEdit-macOS.zip) to install the released package.
- The package source is in [pleum-capcutedit-macos](pleum-capcutedit-macos/).
- Review the generated [distribution audit](Pleum-CapCutEdit-macOS-audit.json), [manifest](Pleum-CapCutEdit-macOS-manifest.json), and [SHA-256 checksums](Pleum-CapCutEdit-macOS-checksums.txt).

The release excludes CapCut projects, media, transcripts, API credentials, local paths, learned styles, and runtime caches. See the package [privacy policy](pleum-capcutedit-macos/PRIVACY.md).
