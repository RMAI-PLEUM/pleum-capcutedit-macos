# Pattern 1 rules

## Priority

1. Clean speech and complete meaning.
2. Readable captions.
3. Semantic emphasis.
4. Decorative polish.

Never sacrifice the first two priorities to add effects.

## Sound and transitions

- Make the hook the densest section, then reduce effect density through the body.
- Use SFX only when it supports a reveal, named term, chapter handoff, precise definition, completed result, warning, or CTA.
- Keep most boundaries as hard cuts. Use a transition only for a meaningful structural change.
- Match template names in the plan to assets in the recipient-owned reference project; do not assume any named asset exists.

## Slow zoom

- Use on a complete clause such as a hook, misconception correction, consequence, result, or warning.
- Prefer subtle linear movement around 4-6% relative scale change unless the recipient's local reference proves otherwise.
- Do not overwrite non-owned keyframes or end a motion mid-clause.

## Text

- Ordinary captions may use one spoken word each.
- Default to `system-default`: plain white text with no bundled font, shadow, stroke, background, bold, scale effect, or animation.
- Karaoke or CTA emphasis changes color only by default. Do not enlarge the highlighted word.
- Suppress a CTA keyword from the ordinary registered caption only when one replacement callout is guaranteed.

## Reject

- Unknown schema or mismatched draft mirrors.
- Missing local assets or ambiguous template matches.
- Effect on every cut, continuous competing SFX, duplicated CTA text, accidental one-frame fragments, or unregistered generated objects.
