# Install for OpenAI Codex

Use Codex skill import/management when available, or keep this repository in the active project and reference its `SKILL.md`. Codex directories vary by version and configuration; verify the installed Codex documentation/configuration rather than hardcoding a personal directory. For repository-level installation run:

`python scripts/install_skill.py --tool codex --project-path PATH --dry-run`

Review the destination, then rerun without `--dry-run`.
