# Local style learning

`system-default` is the bundled neutral preset. It contains no font binary, local path, private project identifier, shadow, stroke, background, scale change, or branded typography. For best compatibility, select a recipient-owned neutral CapCut caption as a read-only reference and learn a local preset. Preserve complete material/segment/track templates, nested unknown fields, placement, flags, and data types. Exclude cue IDs, timing, text, and fixed text-length ranges. Re-learn after moving computers or changing CapCut versions.
