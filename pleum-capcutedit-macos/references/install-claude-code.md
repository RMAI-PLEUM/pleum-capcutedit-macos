# Install for Claude Code

Project installation:

`python scripts/install_skill.py --tool claude-project --project-path PATH --dry-run`

Review and rerun without dry-run. This installs `pleum-capcutedit-macos`, `edit-capcut`, and `pattern-1` under the selected project's `.claude/skills/`. Personal installation under `~/.claude/skills/` occurs only with explicit `--tool claude-personal`.
